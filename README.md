# نظام حجز المواعيد - د. محمد زهران

نظام حجز مواعيد للعيادة يعمل بالكامل في المتصفح (HTML + CSS + JavaScript) بدون خادم.

## هيكل المشروع

```
zahran-booking/
├── index.html        # الصفحة الرئيسية (الحجز + لوحة التحكم)
├── css/
│   └── style.css     # التنسيقات
├── js/
│   ├── app.js        # منطق الحجز والتوجيه
│   └── admin.js      # لوحة التحكم
└── README.md
```

## التشغيل

افتح الملف `index.html` مباشرة في المتصفح، أو فعّل GitHub Pages من:
**Settings → Pages → Deploy from a branch → main / root**.

## الدخول إلى لوحة التحكم

- اكتب `admin` في أي مكان من صفحة الحجز، أو أضف `#admin` إلى الرابط.
- كلمة المرور الافتراضية: `1234` ، غيّرها من تبويب **الإعدادات** فوراً.

## ملاحظات

- البيانات محفوظة في `localStorage` للمتصفح، لذلك تبقى على الجهاز الذي تُدار منه فقط.
- للاستخدام الفعلي من أكثر من جهاز يلزم ربط النظام بقاعدة بيانات وخادم.
- كلمة المرور مخزنة في المتصفح وليست حماية أمنية قوية، وهذا مناسب للنموذج فقط.
